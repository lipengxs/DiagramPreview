## PR1 实现决策

- 固定 Mermaid 11.15.0。独立 parser adapter 通过 `getDiagramFromText` 读取 flowchart/sequence 数据库，按队列解析后立即快照，隔离可变数据库。
- 浏览器负责真实语法解析；无 DOM 时明确失败，不再跳过校验。Node 单元测试验证快照模型和 XML，浏览器测试验证真实源码到实际下载的文件。
- 原始节点 ID 用作身份映射；XML ID 用独立编号，避免中文、同名标签和基础 mxCell ID 冲突。
- 保留节点、边、标签、箭头方向及虚线；支持矩形、圆角矩形、椭圆、菱形。其他形状和格式损失给出提示。
- 子图内部节点展开；连接子图边界、不可可靠转换的箭头和隐形连接会阻止导出。时序图转换为关系图，说明消息顺序和生命线不保留。
- 维持 36 节点/40 连线上限，超过时拒绝，不产生部分文件。
- SVG/PNG/文件下载与成功渲染时的源码、工具 slug、renderer 绑定，输入变化后禁用旧产物。
- 格式兼容工具不再建议离开当前转换器；同时修正无向 Graphviz `graph` 被识别为 Mermaid 的顺序问题。
- 英中正文/FAQ 补支持边界，不修改冻结中的 title/H1。

## PR2 实现决策与验收

- 新增 `POST /api/tools/plantuml`，只访问固定公共 PlantUML 上游，不接受客户端指定渲染器，不跟随重定向，不缓存请求和返回。
- JSON 请求最多 64 KiB（包含 JSON 包装），返回 SVG 最多 2 MiB；同时检查声明长度及实际流字节数。上游超时 10 秒，客户端 12 秒兜底；编辑或离开页面会取消旧请求。
- 识别 HTTP 状态和 PlantUML 错误响应头，语法错误不会被当作成功图片。错误不回显上游包含源码的描述，支持重试；失败或输入变化后禁用 SVG/PNG。
- SVG 经 DOMPurify 及资源属性检查后用于预览和图片下载，移除脚本、超链接、嵌入图片、动画和外部资源。始终可下载当前非空输入的原始 `.puml`，失败时也不会丢失源码。
- PNG 按实际图像尺寸生成，限制单边 8192 px、总计 16,777,216 像素；超大图使用 SVG。修复共享导出器中 Mermaid HTML 标签导致画布不可导出的问题，为响应式 SVG 补齐图像尺寸。
- 导出成功带 `artifact_type`；`.puml` 记为导出，不误记为转换。PNG 失败不发送成功事件。英中说明同步更新，title/H1 不变。
- 验证：22/22 单元测试；36/36 浏览器测试（23 项原有/PR1，13 项 PR2）；typecheck、生产构建通过；核心 SEO 本地审计 35/35。
- 真实公共服务验收：时序、类、用例、活动四种示例均通过本站接口下载 SVG/PNG/原始源码；PNG 分别为 271×308、179×210、323×172、256×268，有实际绘图内容；语法错误返回 400，禁用图片下载，保留源码下载和重试。
- 验收文件和截图：`reports/implementation-2026-10-25/plantuml/README.md`。未部署，未提交 GSC/Bing，不代表已取得搜索流量效果。
