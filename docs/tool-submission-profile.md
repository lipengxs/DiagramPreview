## Detailed Description

DiagramPreview is an online developer diagram workspace built for technical documentation, architecture review, API debugging, and AI-generated diagram validation.

It supports preview and conversion workflows across Mermaid, PlantUML, draw.io / diagrams.net XML, OpenAPI, Postman, HAR, JSON Schema, Zod, TypeScript interfaces, Docker, Kubernetes, Terraform, Graphviz, Markdown, SVG, and more.

Unlike generic diagram tools, DiagramPreview focuses on developer workflows: preview diagram source before publishing, convert Mermaid or PlantUML into editable draw.io files, turn OpenAPI / HAR / Postman data into sequence diagrams, visualize JSON Schema and API payloads, inspect draw.io files before sharing, and export results as SVG, PNG, PDF, Markdown snippets, or downloadable files.

The product runs in the browser, supports local drafts and recent history, and avoids sending diagram source or private technical content to analytics.

中文详细描述：

DiagramPreview 是一个面向开发者场景的在线图表工作台，适合技术文档、架构评审、API 排障、Schema 可视化和 AI 生成图表检查。

它支持 Mermaid、PlantUML、draw.io / diagrams.net XML、OpenAPI、Postman、HAR、JSON Schema、Zod、TypeScript Interface、Docker、Kubernetes、Terraform、Graphviz、Markdown、SVG 等多种技术输入格式。

与普通画图工具不同，DiagramPreview 更关注开发者的真实工作流：发布前预览图表源码，把 Mermaid 或 PlantUML 转成可编辑的 draw.io 文件，把 OpenAPI / HAR / Postman 转成 sequence diagram，可视化 JSON Schema 和 API payload，检查 draw.io 文件结构，并导出 SVG、PNG、PDF、Markdown 片段或可下载文件。

工具在浏览器中运行，支持本地草稿和最近使用记录，不会把用户的 diagram source、源码或 prompt 发送到 GA。
