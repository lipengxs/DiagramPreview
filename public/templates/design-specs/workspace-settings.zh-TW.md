# 工作區設定 — 設計規範

> DiagramPreview 獨立範例，請依產品情況調整；這不是 Figma 官方範本或匯入格式。

## 目標與範圍
讓工作區擁有者修改工作區名稱與通知偏好。
不包含帳單、成員邀請和權限管理。預覽使用虛構資料，不連接正式環境。

## 設計變數
- 主要操作：#1D4ED8，搭配白色文字。
- 正文：#0F172A，背景 #FFFFFF。次要文字：#475569；錯誤文字：#B91C1C。
- 字型：system-ui；正文 16px / 24px；標題 24px / 32px。
- 間距：4、8、12、16、24、32px；卡片圓角：8px。
- 使用有名稱的設計變數，不臨時加入任意顏色或間距。

## 元件與狀態
### 儲存按鈕
- 預設：文案「儲存變更」，使用主要操作背景。
- 懸停：背景 #1E40AF，維持白色文字可讀性。
- 焦點：顯示 2px 外框，與按鈕間隔 2px。
- 停用：未變更或驗證失敗時，在輸入框旁說明錯誤。
- 載入：顯示「儲存中…」，防止重複提交。
- 成功：透過 live region 宣告「變更已儲存」。
- 失敗：顯示行內錯誤並允許重試，保留編輯內容。
### 工作區名稱
- 必填，移除前後空白後為 2–60 個字元。
- 持續顯示標籤與說明；預留文字不能取代標籤。
- 失焦與提交前驗證，錯誤資訊須與輸入框關聯。
- 驗證失敗時不儲存修改。

## 互動與資料
1. 載入目前名稱與通知偏好。
2. 僅在內容有效且有變更時啟用儲存。
3. 提交後模擬請求並顯示載入狀態。
4. 成功後保留確認值並宣告完成。
5. 失敗後保留草稿，提供重試。
- 初始載入：顯示帶有文字說明的佔位內容。
- 初始請求失敗：提供重試，不虛構已儲存的資料。
- 伺服器回傳空名稱時顯示必填提示。

## 響應式版面
- 小於 768px：單列，頁面邊距 16px，儲存按鈕占滿寬度。
- 768px 以上：表單置中，最大寬度 640px，邊距 24px。
- 寬度 320px 時不出現水平捲動。

## 無障礙
- 每個輸入框有程式可識別的標籤，Tab 順序與視覺順序一致。
- 所有互動可透過鍵盤完成，且焦點清楚可見。
- 成功與錯誤用文字說明，不只靠顏色傳達。
- 一般文字與實際背景的對比度至少為 4.5:1。

## 驗收清單
- [ ] 空名稱與純空白名稱不能提交，顯示明確錯誤。
- [ ] 長度不在 2–60 個字元之間時顯示錯誤。
- [ ] 儲存期間重複點擊只發出一次請求。
- [ ] 儲存失敗後保留編輯內容並允許重試。
- [ ] 成功時宣告完成，不強行移動焦點。
- [ ] 通過鍵盤操作與 320px 版面檢查。
- [ ] 所有實作狀態均符合本規範。
