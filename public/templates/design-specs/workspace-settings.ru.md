# Настройки рабочего пространства — спецификация

> Независимый пример DiagramPreview. Адаптируйте к продукту; это не официальный формат Figma.

## Цель и границы
Владелец может менять название и настройку уведомлений.
Оплата, приглашения и управление разрешениями не входят в задачу.
Использовать вымышленные данные без подключения к рабочему серверу.

## Токены дизайна
- Основное действие: #1D4ED8 с белым текстом.
- Текст: #0F172A на #FFFFFF; вторичный: #475569; ошибка: #B91C1C.
- Шрифт: system-ui; текст 16px / 24px; заголовок 24px / 32px.
- Отступы: 4, 8, 12, 16, 24, 32px; радиус карточки: 8px.
- Использовать именованные токены, не добавлять произвольные цвета или отступы.

## Компоненты и состояния
### Кнопка сохранения
- Обычно: «Сохранить изменения», основной фон.
- Наведение: #1E40AF с читаемым белым текстом.
- Фокус: контур 2px с отступом 2px.
- Отключена при отсутствии изменений или ошибках; объяснить ошибку рядом с полем.
- При сохранении показать сообщение и запретить повторную отправку.
- Успех: объявить «Изменения сохранены» через live region.
- При ошибке сохранить ввод и предложить повторить запрос.
### Название
- Обязательно, 2–60 символов после удаления внешних пробелов.
- Постоянная подпись и подсказка; плейсхолдер не заменяет подпись.
- Проверять при потере фокуса и перед сохранением; связать ошибку с полем.
- Невалидные данные не сохранять.

## Взаимодействие и данные
1. Загрузить текущие значения.
2. Включать сохранение только для изменённых валидных значений.
3. Имитировать запрос и показать состояние загрузки.
4. При успехе сохранить подтверждённые значения и объявить завершение.
5. При ошибке сохранить черновик и предложить повторить запрос.
- При начальной загрузке показать текстовый индикатор.
- При начальном сбое предложить повтор, не придумывая сохранённые данные.
- Для пустого названия показать сообщение обязательного поля.

## Адаптивная вёрстка
- При ширине менее 768px: одна колонка, отступ 16px, кнопка на всю ширину.
- От 768px: форма по центру, максимум 640px, отступ 24px.
- При ширине 320px: без горизонтальной прокрутки.

## Доступность
- У каждого поля есть программная подпись; Tab следует визуальному порядку.
- Клавиатура управляет всеми элементами, фокус всегда виден.
- Сообщать успех и ошибки текстом, а не только цветом.
- Проверить контраст обычного текста не менее 4.5:1 на реальном фоне.

## Приёмка

- [ ] За пределами 2–60 символов показать конкретную ошибку.
- [ ] Повторные нажатия при сохранении создают один запрос.
