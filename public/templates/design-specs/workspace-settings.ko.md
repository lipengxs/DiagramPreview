# 작업 공간 설정 — 디자인 명세

> DiagramPreview 독립 예제입니다. 제품에 맞게 수정하세요. Figma 공식 템플릿이나 가져오기 형식이 아닙니다.

## 목적과 범위
소유자가 작업 공간 이름과 알림 설정을 변경할 수 있게 한다.
결제, 초대, 권한 관리는 제외한다. 가상 데이터를 사용하며 운영 서버에 연결하지 않는다.

## 디자인 토큰
- 주요 동작: #1D4ED8 배경과 흰색 글자.
- 본문: #0F172A, 배경 #FFFFFF. 보조 글자: #475569. 오류: #B91C1C.
- 글꼴: system-ui. 본문 16px / 24px, 제목 24px / 32px.
- 간격: 4, 8, 12, 16, 24, 32px. 카드 반경: 8px.
- 이름이 있는 토큰을 사용하고 임의의 색상이나 간격을 추가하지 않는다.

## 구성요소와 상태
### 저장 버튼
- 기본: “변경 사항 저장”, 주요 동작 배경.
- 호버: #1E40AF, 흰색 글자의 가독성 유지.
- 포커스: 2px 외곽선과 2px 간격.
- 변경이 없거나 잘못된 입력이면 비활성화하고 필드 옆에 이유를 설명한다.
- 저장 중에는 메시지를 표시하고 중복 전송을 방지한다.
- 성공: live region으로 “변경 사항 저장됨”을 알린다.
- 오류 발생 시 입력을 유지하고 재시도를 제공한다.
### 작업 공간 이름
- 필수. 앞뒤 공백 제거 후 2~60자.
- 라벨과 도움말을 항상 표시하며 자리표시자로 대체하지 않는다.
- 포커스를 잃을 때와 저장 전에 검증하고 오류를 필드에 연결한다.
- 검증 실패 시 저장하지 않는다.

## 상호작용과 데이터
1. 현재 이름과 알림 설정을 불러온다.
2. 유효한 변경이 있을 때만 저장을 활성화한다.
3. 전송 시 모의 요청을 실행하고 로딩 상태를 표시한다.
4. 성공 시 확정 값을 유지하고 완료를 알린다.
5. 실패 시 초안을 유지하고 재시도를 제공한다.
- 초기 로딩에는 설명이 있는 자리표시자를 표시한다.
- 초기 요청 실패 시 재시도를 제공하며 저장 데이터를 꾸며내지 않는다.
- 빈 이름이면 필수 입력 메시지를 표시한다.

## 반응형 배치
- 768px 미만: 한 열, 여백 16px, 저장 버튼 전체 너비.
- 768px 이상: 가운데 배치, 최대 너비 640px, 여백 24px.
- 너비 320px에서 가로 스크롤이 생기지 않는다.

## 접근성
- 각 입력에 프로그램으로 인식 가능한 라벨을 제공하며 Tab은 시각적 순서를 따른다.
- 키보드로 모든 동작을 수행하고 포커스가 보이게 한다.
- 성공과 오류는 색상뿐 아니라 텍스트로 전달한다.
- 일반 텍스트와 실제 배경의 명암비를 4.5:1 이상으로 확인한다.

## 인수 체크리스트
- [ ] 빈 이름은 오류를 표시하고 전송할 수 없게 한다.
- [ ] 2~60자 범위를 벗어나면 구체적인 오류를 표시한다.
- [ ] 저장 중 여러 번 클릭해도 요청은 한 번만 보낸다.
- [ ] 실패 시 입력을 유지하고 재시도할 수 있다.
- [ ] 포커스를 이동하지 않고 완료 알림을 제공한다.
- [ ] 키보드 조작과 너비 320px 화면을 검사한다.
- [ ] 구현한 모든 상태를 명세와 비교한다.
